# Synthetic load packs for the Grounding Trial Viewer

Two packs are included:
- **`combined/`**: all 37 candidates and 309 reports. This is the original trial (C1–C9, SAMPLE-001…036) merged with Sample B (B01–B28, SYNB-###). It is also the viewer's built-in data.
- **`sample_b/`**: Sample B on its own.

## Combined (`combined/`, 7 files)
To load it, select all seven files at once. It includes `grounding_results_llm.json`, the constrained-prompt answers for C1–C9.

Results of the rules selector (`--max-reports 12`):
- **Parent category:** right for 35 of 37 candidates.
- **Report links, strict scoring:** precision 83%, recall 79%.
- **Report links, counting overlaps:** precision 89%, recall 84%.
- **Status:** 23 grounded, 9 needs review, 5 not grounded.
- **Guardrail tests:** 6 of 6 blocked.

**Overlapping candidates.** Eight of the original candidates have a near-twin in Sample B:

| Original | Near-twin in Sample B |
|---|---|
| C1 | B02 |
| C2 | B01 and B27 |
| C3 | B04 |
| C4 | B26 |
| C5 | B08 |
| C7 | B15 |
| C8 | B14 |
| C9 | B22 |

Each pair comes from a different batch but describes the same kind of event, so the sibling rule splits their reports between them. As a result:
- C1, C3, C7 and B01 drop to *not grounded*;
- each batch's answer key counts the other batch's reports as wrong.

The *counting overlaps* score does not count a report given to the near-twin as an error. The lesson for the pipeline is to **merge duplicate candidates (discovery step) before grounding**. The viewer flags each overlap on the candidate page.

# Sample B on its own

All reports are **synthetic** (keys SYNB-###), generated by `tools/generate_sample_b.py --seed 7`.
They are not real events. The definitions are short paraphrases of the named sources.

## How to load Sample B
Open `grounding_viewer.html` (or the published viewer), click **Load results**, and select all six files in `sample_b/` at once:

| File | Fills |
|---|---|
| grounding_results.json | Candidates, Matrix, Compare tabs (28 candidates, B01–B28) |
| guardrail_tests.csv | Guardrails tab (6 faulty answers, all blocked) |
| parent_selection.csv | Parents tab (definition-only vs vote-only vs combined) |
| sample_reports.json | Report text, evidence quotes and the Try tab (273 reports: 213 candidate, 60 background) |
| industry_definitions.json | Definition text (41 definitions) |
| icao_categories.json | Parent names (20 CICTT categories, incl. WSTRW and USOS) |

## Results (run with `--max-reports 12`)
- Parent correct 27/28 (definition only 18/28, vote only 26/28)
- Report precision 93%, recall 90%
- 20 grounded, 6 needs review, 2 not grounded

## Make your own
```
python tools/combine_datasets.py --inputs data data_sample_b --out data_combined
python run_trial.py --db ... --data data_combined --out out_combined --max-reports 12 --llm-outputs out/llm_answers   # prompt answers (C1–C9)
python run_trial.py --db ... --data data_combined --out out_combined --max-reports 12                               # rules run last
```

python tools/generate_sample_b.py --seed 11 --scale 2 --background 100 --out data_sample_c
